# Filet de sécurité réseau

> Je travaille sur une machine loué dont je n'ai pas d'accès physique. Une mauvaise configuration peut donc me couper l'accès à la machine. Afin d'anticiper ce problème, je programme un retour arrière différé avec les commandes `at` et `ifreload` qui restaure la configuration initiale.
